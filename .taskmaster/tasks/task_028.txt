   ```java
   @RestController
   @RequestMapping("/api/v1")
   public class ExternalApiController {

       @PostMapping("/chat/{agentId}")
       public ResponseEntity<ExternalChatResponse> chat(
           @PathVariable Long agentId,
           @RequestBody ExternalChatRequest request,
           @RequestHeader(value = "X-API-Key", required = false) String apiKeyHeader,
           @RequestHeader(value = "Authorization", required = false) String authHeader) {

           // API 키 인증
           String apiKey = extractApiKey(apiKeyHeader, authHeader);
           ApiKey validatedKey = apiKeyService.validateApiKey(apiKey);
           Long userId = validatedKey.getUser().getId();

           // 에이전트 소유권 확인
           Agent agent = agentService.getAgentWithOwnerCheck(agentId, userId);

           // 채팅 처리
           ChatMessageResponse response = chatService.chat(agentId, toChatRequest(request), userId);

           // 사용량 로깅
           usageService.logApiUsage(validatedKey, agentId, response);

           return ResponseEntity.ok(toExternalResponse(response));
       }

       @PostMapping("/chat/{agentId}/stream")
       public Flux<ServerSentEvent<String>> chatStream(
           @PathVariable Long agentId,
           @RequestBody ExternalChatRequest request,
           @RequestHeader("X-API-Key") String apiKey) {

           // 인증 및 처리...

           return chatService.chatStream(agentId, toChatRequest(request), userId)
               .map(content -> ServerSentEvent.<String>builder()
                   .data(objectMapper.writeValueAsString(Map.of("content", content)))
                   .build());
       }
   }
   ```

3. 에러 응답 표준화
   ```java
   @Data
   @Builder
   public class ExternalErrorResponse {
       private String error;
       private String message;
       private Integer status;
       private Long timestamp;
   }

   @RestControllerAdvice
   public class ExternalApiExceptionHandler {

       @ExceptionHandler(InvalidApiKeyException.class)
       public ResponseEntity<ExternalErrorResponse> handleInvalidApiKey(InvalidApiKeyException e) {
           return ResponseEntity.status(401).body(ExternalErrorResponse.builder()
               .error("unauthorized")
               .message("Invalid API key")
               .status(401)
               .timestamp(System.currentTimeMillis())
               .build());
       }

       @ExceptionHandler(AgentNotFoundException.class)
       public ResponseEntity<ExternalErrorResponse> handleAgentNotFound(AgentNotFoundException e) {
           return ResponseEntity.status(404).body(ExternalErrorResponse.builder()
               .error("not_found")
               .message("Agent not found")
               .status(404)
               .timestamp(System.currentTimeMillis())
               .build());
       }

       @ExceptionHandler(RateLimitExceededException.class)
       public ResponseEntity<ExternalErrorResponse> handleRateLimit(RateLimitExceededException e) {
           return ResponseEntity.status(429).body(ExternalErrorResponse.builder()
               .error("rate_limit_exceeded")
               .message("Too many requests. Please try again later.")
               .status(429)
               .timestamp(System.currentTimeMillis())
               .build());
       }
   }
   ```

   ```java
               .totalTokens(response.getUsage().getTotalTokens())

               .createdAt(LocalDateTime.now())
               .build();

           usageLogRepository.save(log);
       }
   }
   ```

5. Rate Limiting (API 키별)
   ```java
   @Component
   public class ApiKeyRateLimiter {

       private final Map<Long, Bucket> buckets = new ConcurrentHashMap<>();

       public void checkRateLimit(ApiKey apiKey) {
           Bucket bucket = buckets.computeIfAbsent(apiKey.getId(), this::createBucket);

           if (!bucket.tryConsume(1)) {
               throw new RateLimitExceededException("Rate limit exceeded");
           }
       }

       private Bucket createBucket(Long apiKeyId) {
           // 분당 60 요청
           Bandwidth limit = Bandwidth.classic(60, Refill.intervally(60, Duration.ofMinutes(1)));
           return Bucket.builder().addLimit(limit).build();
       }
   }
   ```

6. curl 사용 예시 (문서용)

   ```bash
     -H "X-API-Key: ak_your_api_key_here" \
     -d '{
       "message": "좀 더 자세히 알려주세요",
       "conversationId": "conv_abc123"
     }'

   # 스트리밍 응답
   curl -X POST https://your-domain.com/api/v1/chat/123/stream \
     -H "Content-Type: application/json" \
     -H "X-API-Key: ak_your_api_key_here" \
     -N \
     -d '{
       "message": "긴 글을 작성해주세요"
     }'
   ```
