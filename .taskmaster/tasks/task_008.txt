1. OllamaConnector 클래스 구현
   ```java
   @Component
   public class OllamaConnector implements LlmConnector {
       private final WebClient webClient;
       private final LlmServer server;

       public OllamaConnector(LlmServer server) {
           this.server = server;
           this.webClient = WebClient.builder()
               .baseUrl(server.getBaseUrl())
               .defaultHeader(HttpHeaders.CONTENT_TYPE, MediaType.APPLICATION_JSON_VALUE)
               .build();
       }
   }
   ```

2. 연결 테스트 (GET /)
   ```java
   @Override
   public boolean testConnection() {
       try {
           String response = webClient.get()
               .uri("/")
               .retrieve()
               .bodyToMono(String.class)
               .timeout(Duration.ofSeconds(5))
               .block();
           return response != null && response.contains("Ollama");
       } catch (Exception e) {
           return false;
       }
   }
   ```

3. 모델 목록 조회 (GET /api/tags)
   ```java
   @Override
   public List<ModelInfo> listModels() {
       OllamaTagsResponse response = webClient.get()
           .uri("/api/tags")
           .retrieve()
           .bodyToMono(OllamaTagsResponse.class)
           .block();

       return response.getModels().stream()
           .map(m -> new ModelInfo(m.getName(), m.getSize(), m.getModifiedAt()))
           .collect(Collectors.toList());
   }

   // Ollama 응답 DTO
   @Data
   public class OllamaTagsResponse {
       private List<OllamaModel> models;
   }
   ```

4. 채팅 완성 (POST /api/chat)
   ```java
   @Override
   public ChatResponse chat(ChatRequest request) {
       OllamaChatRequest ollamaRequest = OllamaChatRequest.builder()
           .model(request.getModel())
           .messages(convertMessages(request.getMessages()))
           .stream(false)
           .options(OllamaOptions.builder()
               .temperature(request.getTemperature())
               .num_predict(request.getMaxTokens())
               .build())
           .build();

       OllamaChatResponse response = webClient.post()
           .uri("/api/chat")
           .bodyValue(ollamaRequest)
           .retrieve()
           .bodyToMono(OllamaChatResponse.class)
           .block();

       return ChatResponse.builder()
           .content(response.getMessage().getContent())
           .model(response.getModel())
           .totalDuration(response.getTotalDuration())
           .build();
   }
   ```

5. 스트리밍 응답 (POST /api/chat with stream=true)
   ```java
   @Override
   public Flux<String> chatStream(ChatRequest request) {
       OllamaChatRequest ollamaRequest = OllamaChatRequest.builder()
           .model(request.getModel())
           .messages(convertMessages(request.getMessages()))
           .stream(true)
           .build();

       return webClient.post()
           .uri("/api/chat")
           .bodyValue(ollamaRequest)
           .retrieve()
           .bodyToFlux(OllamaStreamResponse.class)
           .map(r -> r.getMessage().getContent())
           .takeUntil(r -> r.isDone());
   }
   ```

6. 텍스트 생성 (POST /api/generate)

   public GenerateResponse generate(GenerateRequest request) {
       OllamaGenerateRequest ollamaRequest = OllamaGenerateRequest.builder()

       OllamaGenerateResponse response = webClient.post()
           .uri("/api/generate")

           .block();

       return new GenerateResponse(response.getResponse());
   }
