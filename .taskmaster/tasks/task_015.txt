3. URL/Body 템플릿 처리
   ```java
   private String processTemplate(String template, Map<String, Object> params) {
       if (template == null) return null;

       String result = template;
       for (Map.Entry<String, Object> entry : params.entrySet()) {
           String placeholder = "{{" + entry.getKey() + "}}";
           String value = entry.getValue() != null
               ? entry.getValue().toString()
               : "";
           result = result.replace(placeholder, URLEncoder.encode(value, StandardCharsets.UTF_8));
       }
       return result;
   }
   ```

4. HTTP 요청 실행
   ```java
   @Override
   public Object execute(Function function, Map<String, Object> parameters) {
       HttpApiImplementation config = parseImplementation(function.getImplementation());

       // URL 템플릿 처리
       String url = processTemplate(config.getUrl(), parameters);

       // WebClient 요청 구성
       WebClient.RequestBodySpec request = webClient
           .method(HttpMethod.valueOf(config.getMethod()))
           .uri(url);

       // 헤더 추가
       if (config.getHeaders() != null) {
           config.getHeaders().forEach((key, value) -> {
               request.header(key, processTemplate(value, parameters));
           });
       }

       // Body 추가 (POST, PUT)
       if (config.getBody() != null && !config.getMethod().equals("GET")) {
           String body = processTemplate(config.getBody(), parameters);
           request.bodyValue(body);
       }

       // 요청 실행
       String response = request
           .retrieve()
           .bodyToMono(String.class)
           .timeout(Duration.ofMillis(config.getTimeout() != null ? config.getTimeout() : 30000))
           .block();

       // 응답 매핑 (JSONPath)
       if (config.getResponseMapping() != null) {
           return extractWithJsonPath(response, config.getResponseMapping());
       }

       return response;
   }
   ```

5. JSONPath 응답 매핑
   ```java
   private Object extractWithJsonPath(String json, String path) {
       try {
           DocumentContext context = JsonPath.parse(json);
           return context.read(path);
       } catch (PathNotFoundException e) {
           throw new FunctionExecutionException("JSONPath 경로를 찾을 수 없습니다: " + path);
       }
   }
   ```

6. 에러 처리
   ```java
   .onStatus(HttpStatusCode::isError, response -> {
       return response.bodyToMono(String.class)
           .flatMap(body -> Mono.error(
               new FunctionExecutionException(
                   "HTTP 오류 " + response.statusCode() + ": " + body)));
   })
   ```

7. 보안 고려사항

   ```java
   // URL 화이트리스트 검증 (옵션)
   private void validateUrl(String url) {
       // 내부 네트워크 접근 차단
       if (url.contains("localhost") || url.contains("127.0.0.1")) {
           throw new SecurityException("내부 네트워크 접근이 차단되었습니다");
       }
   }

   // 민감 헤더 마스킹 (로깅 시)
   private Map<String, String> maskSensitiveHeaders(Map<String, String> headers) {
       return headers.entrySet().stream()
           .collect(Collectors.toMap(
               Map.Entry::getKey,
               e -> e.getKey().equalsIgnoreCase("Authorization")
                   ? "***" : e.getValue()
           ));
   }
   ```
