[상세 구현 가이드]
1. 프로젝트 생성
   - Spring Initializr (https://start.spring.io) 사용 또는 IDE에서 직접 생성
   - Java 17+ 버전 선택
   - Spring Boot 3.x 최신 버전 선택
   - Gradle (Kotlin DSL) 또는 Maven 선택

2. 필수 의존성 추가
   - spring-boot-starter-web: REST API 개발
   - spring-boot-starter-data-jpa: 데이터베이스 연동
   - spring-boot-starter-security: 인증/인가
   - spring-boot-starter-validation: 입력값 검증
   - postgresql: PostgreSQL 드라이버
   - lombok: 보일러플레이트 코드 감소

3. application.yml 기본 설정
   ```yaml
   server:
     port: 8080

   spring:
     datasource:
       url: jdbc:postgresql://localhost:5432/aiagent
       username: ${DB_USERNAME}
       password: ${DB_PASSWORD}
     jpa:
       hibernate:
         ddl-auto: update
       show-sql: true
   ```

4. 프로젝트 구조 설정
   ```
   src/main/java/com/aiagent/
   ├── controller/     # REST 컨트롤러
   ├── service/        # 비즈니스 로직
   ├── repository/     # 데이터 액세스
   ├── entity/         # JPA 엔티티
   ├── dto/            # 데이터 전송 객체
   ├── config/         # 설정 클래스
   ├── security/       # 보안 관련
   └── exception/      # 예외 처리
   ```

5. 기본 설정 클래스 작성
   - WebConfig: CORS 설정
   - JpaConfig: Auditing 설정
