2. LlmServerController API
   ```java
   @RestController
   @RequestMapping("/api/llm-servers")
   public class LlmServerController {

       @GetMapping
       public List<LlmServerResponse> getServers();

       @PostMapping
       public LlmServerResponse createServer(@RequestBody LlmServerRequest req);

       @GetMapping("/{id}")
       public LlmServerResponse getServer(@PathVariable Long id);

       @PutMapping("/{id}")
       public LlmServerResponse updateServer(@PathVariable Long id,
                                             @RequestBody LlmServerRequest req);

       @DeleteMapping("/{id}")
       public void deleteServer(@PathVariable Long id);

       @PostMapping("/{id}/test")
       public ConnectionTestResult testConnection(@PathVariable Long id);

       @GetMapping("/{id}/models")
       public List<ModelInfo> getModels(@PathVariable Long id);
   }
   ```

4. LlmConnectorFactory
   ```java
   @Component
   public class LlmConnectorFactory {
       public LlmConnector getConnector(LlmServer server) {
           return switch (server.getType()) {
               case OLLAMA -> new OllamaConnector(server);
               case VLLM -> new VllmConnector(server);
               case LOCAL_AI -> new LocalAiConnector(server);
               case CUSTOM -> new CustomConnector(server);
           };
       }
   }
   ```

6. DTO 정의
   ```java
   // LlmServerRequest
   @Data
   public class LlmServerRequest {
       @NotBlank
       private String name;

       @NotNull
       private LlmServerType type;  // OLLAMA, VLLM, LOCAL_AI, CUSTOM

       @NotBlank
       private String baseUrl;

       private String authToken;  // 옵션
   }

   // LlmServerResponse
   @Data
   public class LlmServerResponse {
       private Long id;
       private String name;
       private LlmServerType type;
       private String baseUrl;
       private Boolean isActive;
       private LocalDateTime createdAt;
       // authToken은 응답에 포함하지 않음
   }
   ```

7. 연결 테스트 로직
   ```java
   public ConnectionTestResult testConnection(Long id) {
       LlmServer server = repository.findById(id).orElseThrow();
       LlmConnector connector = connectorFactory.getConnector(server);

       try {
           boolean success = connector.testConnection();
           return new ConnectionTestResult(success, null);
       } catch (Exception e) {
           return new ConnectionTestResult(false, e.getMessage());
       }
   }
   ```
