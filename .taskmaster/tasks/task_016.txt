2. 함수 스키마 변환 서비스
   ```java
   @Service
   public class FunctionSchemaService {

       public List<JsonNode> getToolsSchema(Agent agent) {
           return agent.getFunctions().stream()
               .map(this::convertToToolSchema)
               .collect(Collectors.toList());
       }

       private JsonNode convertToToolSchema(Function function) {
           ObjectNode tool = objectMapper.createObjectNode();
           tool.put("type", "function");

           ObjectNode functionNode = tool.putObject("function");
           functionNode.put("name", function.getName());
           functionNode.put("description", function.getDescription());

           ObjectNode parameters = functionNode.putObject("parameters");
           parameters.put("type", "object");

           ObjectNode properties = parameters.putObject("properties");
           ArrayNode required = parameters.putArray("required");

           for (ParameterDefinition param : function.getParameters()) {
               ObjectNode prop = properties.putObject(param.getName());
               prop.put("type", param.getType().getJsonType());
               if (param.getDescription() != null) {
                   prop.put("description", param.getDescription());
               }
               if (param.getEnumValues() != null) {
                   prop.set("enum", param.getEnumValues());
               }
               if (param.isRequired()) {
                   required.add(param.getName());
               }
           }

           return tool;
       }
   }
   ```

3. ChatService 수정 (Function Calling 포함)
   ```java
   public ChatMessageResponse chatWithFunctions(Long agentId, ChatMessageRequest request, Long userId) {
       Agent agent = getAgentWithFunctions(agentId, userId);
       List<JsonNode> tools = functionSchemaService.getToolsSchema(agent);

       List<Message> messages = buildMessages(agent, request);

       // 최대 반복 횟수 (무한 루프 방지)
       int maxIterations = 5;
       int iteration = 0;

       while (iteration < maxIterations) {
           ChatRequest llmRequest = ChatRequest.builder()
               .model(agent.getModelName())
               .messages(messages)
               .tools(tools.isEmpty() ? null : tools)
               .temperature(agent.getTemperature())
               .build();

           ChatResponse response = connector.chat(llmRequest);

           // Function call 확인
           if (response.getToolCalls() != null && !response.getToolCalls().isEmpty()) {
               // 어시스턴트 메시지 추가 (tool_calls 포함)
               messages.add(Message.assistant(response.getContent(), response.getToolCalls()));

               // 각 함수 실행
               for (ToolCall toolCall : response.getToolCalls()) {
                   Object result = executeFunctionCall(agent, toolCall);

                   // 함수 결과를 메시지에 추가
                   messages.add(Message.tool(toolCall.getId(), result.toString()));
               }

               iteration++;
           } else {
               // 함수 호출 없음 - 최종 응답
               return ChatMessageResponse.builder()
                   .content(response.getContent())
                   .functionCalls(collectFunctionCalls(messages))
                   .build();
           }
       }

       throw new MaxIterationsExceededException("함수 호출 최대 횟수 초과");
   }
   ```

4. 함수 실행 로직
   ```java
   private Object executeFunctionCall(Agent agent, ToolCall toolCall) {
       String functionName = toolCall.getFunction().getName();
       Map<String, Object> arguments = parseArguments(toolCall.getFunction().getArguments());

       // 에이전트에 연결된 함수 중 매칭되는 것 찾기
       Function function = agent.getFunctions().stream()
           .filter(f -> f.getName().equals(functionName))
           .findFirst()
           .orElseThrow(() -> new FunctionNotFoundException(functionName));

       // 함수 실행
       FunctionExecutor executor = executorFactory.getExecutor(function.getImplementationType());
       Object result = executor.execute(function, arguments);

       // 실행 로그 저장
       saveFunctionExecutionLog(function, arguments, result);

       return result;
   }
   ```
